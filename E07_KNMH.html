Documentación Técnica de Enlace Externo

El siguiente hipervínculo utiliza el elemento ejecutable configurado con la propiedad hacia un recurso HTTP externo localizador de hardware. Se implementa el atributo para instruir al navegador la apertura del sitio objetivo en un contexto de navegación independiente (nueva pestaña), garantizando la no interrupción de la sesión actual. Adicionalmente, se incluye el atributo para mitigar riesgos de seguridad como la vulnerabilidad de acceso cruzado.
