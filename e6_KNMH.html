Introducción al Diseño WEB

El diseño web es el proceso de planificación, estructuración y desarrollo de interfaces digitales accesibles mediante un navegador web. Este proceso incluye la organización del contenido, la composición visual, la usabilidad y la experiencia del usuario.

HTML es un lenguaje de marcado utilizado para estructurar el contenido de una página web. Mediante elementos como encabezados, párrafos, enlaces e imágenes, es posible crear una estructura semántica que facilite la interpretación del contenido por parte del navegador.

CSS es una tecnología utilizada para definir la presentación visual de un sitio web. Permite modificar colores, tipografías, tamaños, espacios y distribución de los elementos, logrando interfaces atractivas y adaptables a diferentes dispositivos.
