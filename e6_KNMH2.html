Desarrollo y Usabilidad WEB

El desarrollo web consiste en crear y estructurar sitios mediante tecnologías como HTML, CSS y JavaScript. Estas herramientas permiten construir páginas con una estructura organizada, una presentación visual adecuada y diferentes funcionalidades interactivas.

La usabilidad web busca que los usuarios puedan navegar por un sitio de manera sencilla y eficiente. Para esto se utilizan elementos como una navegación clara, una correcta jerarquía visual y un diseño adaptable a diferentes tamaños de pantalla.

Los hipervínculos permiten conectar diferentes páginas dentro de un mismo sitio web. En HTML se utiliza la etiqueta <a> junto con el atributo href para establecer la dirección de destino de otra página mediante una ruta relativa.
